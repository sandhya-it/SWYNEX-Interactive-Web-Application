# 💰 ExpenseWise – Smart Expense Tracker

ExpenseWise is a modern expense tracking application that helps users manage their income, monitor expenses, set budgets, and analyze spending habits through an interactive dashboard.

## ✨ Features

- 📊 **Dashboard:** View total income, expenses, balance, and savings.
- 💸 **Transaction Management:** Add, edit, and delete income and expense records.
- 🗂️ **Category Tracking:** Organize transactions by spending categories.
- 📈 **Visual Analytics:** Understand spending patterns through interactive charts.
- 🎯 **Budget Management:** Set budgets and monitor spending limits.
- 🔍 **Search and Filters:** Find transactions by category, date, or type.
- ✅ **Form Validation:** Prevent invalid transaction entries with helpful error messages.
- 💾 **Data Persistence:** Store transaction data locally using LocalStorage.
- 📱 **Responsive Design:** Use the application on desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **State Management:** React Hooks
- **Form Validation:** React Hook Form and Zod
- **Charts:** Recharts
- **Icons:** Lucide React
- **Storage:** Browser LocalStorage


## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sandhya-it/SWYNEX-Interactive-Web-Application.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ExpenseWise
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
